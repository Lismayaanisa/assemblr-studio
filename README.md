# Assemblr Studio: login, register, and setup moment prototype

A static prototype of the Assemblr Studio first-run journey, duplicated from the
Assemblr EDU login, register, and setup moment. The flow and interactions match.
The color follows the Assemblr Studio logo: blue `#2B6FD8` / `#3FA3E8` with a little
light pink `#F4A3C6`, instead of the EDU palette.

English and Indonesian.

```bash
python3 dev-server.py 8766   # http://127.0.0.1:8766/index.html, live reload
```

No build step and no dependencies beyond Python 3.
